# Discord Bot + Web-интерфейс

Проект, содержащий в себе связку из бота + веб интерфейса к нему. Пока что название не было придумано, ведь проект находится на ранней стадии разработки. Поэтому, по моему мнению, этот проект не нуждается в развёрнутом описании на данный момент.

## Технологии

- **Бот**: Python, discord.py
- **Бэкенд API**: Python, FastAPI
- **База данных**: PostgreSQL
- **Веб-интерфейс**: C#

## Структура проекта
.
├── bot/                    # Бот
│   ├── src/                # Основной код бота
│   │   └── main.py         # Исполняемый файл бота           
│   └── requirements.txt    # Файл рекомендаций к использованию
├── web/                    # Веб интерфейс
│   └── requirements.txt    # Файл рекомендаций к использованию
├── .gitignore              # Игнорируемые файлы
├── CODEOWNERS              # Владельцы репозитория
└── README.md               # Этот файл
